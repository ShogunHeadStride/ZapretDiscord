## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем пункт "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query` (провайдер Cloudflare может быть заблокирован)
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы — [инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, настройка и работа Secure DNS на компьютере могут быть нарушены

2. Получите zip/rar-архив с [последнего релиза](https://github.com/ShogunHeadStride/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и включите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот этап можно не выполнять

4. Распакуйте архив в каталог, путь к которому не содержит кириллических символов и специальных знаков

5. Запустите подходящий файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для установки стратегии в автозапуск выберите **`service.bat`** -> `Install Service` -> *нужную стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки разных стратегий. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящий вариант**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — установить выбранную стратегию в автозапуск (services.msc)</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая стратегию в автозапуске и WinDivert
  - **`Game Filter`** — изменить режим обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения этого параметра стратегию нужно перезапустить.**  
  Текущее состояние (включено или выключено) отображается в скобках.
  - **`IPSet Filter`** — изменить режим обхода ресурсов из `ipset-all.txt`.  
  Опция полезна при диагностике, если ресурс без zapret работает, а с ним — нет.  
  Текущий режим указан в скобках:
    - `none` — ни один IP не проверяется
    - `loaded` — IP проверяется на наличие в списке
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включить или отключить автоматический поиск обновлений
  - **`Replace active fakes`** — заменить используемый фейк на другой файл из каталога `bin`
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и соединения с голосовым чатом Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — проверить распространённые причины неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапного прекращения работы клиента
  - **`Run Tests`** — открыть инструмент проверки стратегий:
    - `Standard tests` — протестировать сайты из `utils/targets.txt`
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться winws.exe (обход), видимый на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/ShogunHeadStride/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните в ней команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося Блокнота
  - С помощью текстового редактора, запущенного от имени администратора, откройте файл `hosts` в созданной папке
  - Вставьте скопированный текст в конец `hosts` (либо замените ранее добавленный аналогичный фрагмент)
  - Сохраните файл и проверьте подключение ещё раз. Если результата нет, убедитесь, что `hosts` действительно сохранился.

#### Работа не гарантирована. Если способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/ShogunHeadStride/tg-ws-proxy) или любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> Стратегия, которая некоторое время успешно обходила блокировку, позднее может перестать работать после её обнаружения.
> Здесь собрано много разных стратегий обхода. Если готовые варианты не подходят, создайте новую стратегию на основе одной из существующих и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Запустите `service.bat` -> `Run Diagnostics` и убедитесь, что диагностика не сообщает об ошибках

- Проверьте, что нужный адрес присутствует в списках доменов или IP

- Переберите другие стратегии, в том числе **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/ShogunHeadStride/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; если найдены ошибки, исправьте их, затем в конце выберите Y
- Удалите старый каталог zapret
- Скачайте последнюю версию [со страницы релизов](https://github.com/ShogunHeadStride/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа есть пункт разблокировки, отметьте его, затем нажмите применить и ОК
- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов
- По очереди запускайте разные скрипты `general` и проверяйте интернет-ресурсы. Если выбранная стратегия не работает, закройте программу через значок замочка на панели задач и попробуйте следующую
- После нахождения рабочей стратегии установите её в автозапуск через `service.bat` -> `Install Service` -> выбор нужной стратегии

### Не работает игра/приложение с включённым запретом

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит ругается на WinDivert

- Инструкция по этому случаю опубликована здесь: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- Замените в каталоге [`bin`](./bin) файлы `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Определите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS настроен](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Испытайте остальные стратегии, особенно если выбранная ранее перестала работать.
- См. также [#251](https://github.com/ShogunHeadStride/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS включён](#%EF%B8%8Fиспользование)
- Для начала желательно определить стратегию, на которой открывается YouTube, и запустить её
- Через `service.bat` -> `Run Diagnostics` очистите кэш Discord
- Проверьте приложение Discord после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ей
- Если Discord не открывается и в браузере, снова переберите стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/ShogunHeadStride/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/ShogunHeadStride/tg-ws-proxy)
- Либо подключитесь к бесплатному MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Самый универсальный порядок действий:
- обновите ipset через `service.bat` и включите `Game Filter`
- если это не помогло, дополнительно включите режим `ipset any`

Учтите: после включения `ipset any` многие сайты могут перестать открываться. Не оставляйте этот режим включённым постоянно. Лучше выяснить все IP-адреса, используемые игрой, и добавить их в `ipset-all.txt`

Если результат отсутствует, создайте обсуждение в разделе [Discussions](https://github.com/ShogunHeadStride/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [здесь](https://github.com/ShogunHeadStride/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены-исключения, например когда IP сети есть в `ipset-all.txt`, но конкретный домен этой сети фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
