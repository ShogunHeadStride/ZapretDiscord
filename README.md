## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и выберите отдельного поставщика услуг DNS, а не вариант "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS в настройках самой ОС - [инструкция доступна здесь](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот вариант рекомендуется
    * Владельцам роутеров Keenetic следует активировать настройку "Транзит запросов". При отключенной настройке Secure DNS на компьютере может работать некорректно

2. Загрузите zip/rar-архив с [последним релизом](https://github.com/ShogunHeadStride/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и включите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот пункт можно не выполнять

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите необходимый файл
    * Для поиска подходящей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы включить автозапуск, выберите в **`service.bat`** пункт `Install Service`, затем укажите подходящую стратегию

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск выбранной стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте работающий у вас вариант**

- [**`service.bat`**](./service.bat) - установка автозапуска и дополнительные операции:
  - <ins>**`Install Service`** - добавление выбранной стратегии в автозапуск Windows (services.msc)</ins>
  - **`Remove Services`** - удаление стратегии и WinDivert из списка служб
  - **`Check Status`** - просмотр состояния обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** - изменение режима обхода для игр и других сервисов, использующих UDP и TCP-порты выше 1023.  
  **После изменения необходимо перезапустить стратегию.**  
  В скобках отображается, включена функция или выключена.
  - **`IPSet Filter`** - управление обходом сервисов из `ipset-all.txt`.  
  Этот режим полезен при проверке ресурса, который без zapret работает, а с ним перестал открываться  
  В скобках указано текущее состояние:
    - `none` - проверка не распространяется ни на один IP
    - `loaded` - IP сопоставляются со списком
    - `any` - фильтруется любой IP  
  - **`Auto-Update Check`** - включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** - замена текущего фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** - загрузка свежего `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** - ручная проверка наличия обновлений
  - **`Run Diagnostics`** - поиск распространённых причин неисправности zapret.  
  В конце процедуры доступна очистка кэша <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапного прекращения работы
  - **`Run Tests`** - запуск проверки стратегий:
    - `Standard tests` - тестирование сайтов, перечисленных в `utils/targets.txt`
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), видимый на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/ShogunHeadStride/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и выполните **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Выделите и скопируйте весь текст из открытого блокнота
  - С правами администратора откройте текстовый файл `hosts` в созданной папке
  - Вставьте скопированный текст в конец `hosts` либо замените ранее добавленные аналогичные строки
  - Сохраните файл и снова проверьте подключение. Если результата нет, убедитесь, что изменения действительно записались.

#### Результат не гарантирован. Если веб-версия не заработала, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/ShogunHeadStride/tg-ws-proxy) или одним из публичных прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Вариант, который некоторое время работал, позднее может перестать действовать после его обнаружения.
> В проекте собрано много стратегий обхода. Если готовые варианты не помогают, создайте новую стратегию на основе одной из них и измените её параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте результаты `service.bat` -> `Run Diagnostics` и устраните найденные ошибки

- Убедитесь, что нужный адрес присутствует в списках доменов или IP-адресов

- Проверьте остальные стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/ShogunHeadStride/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; исправьте ошибки и в конце подтвердите действие клавишей Y
- Удалите текущую папку zapret
- Скачайте свежую версию со [страницы релизов](https://github.com/ShogunHeadStride/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Откройте свойства архива правой кнопкой мыши. Если внизу справа есть флажок разблокировки, установите его, нажмите применить и затем ОК
- Распакуйте архив в новую папку в корне диска, без пробелов и специальных символов
- Запускайте разные скрипты `general` и проверяйте интернет-ресурсы. Если выбранный вариант не работает, закройте программу через значок замка на панели задач и попробуйте следующий
- После нахождения рабочей стратегии включите её автозапуск через `service.bat` -> `Install Service`

### Не работает игра/приложение с включённым запретом

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит ругается на WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. В командной строке Windows, открытой через Win+R и `cmd`, найдите имя службы:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS настроен](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал противодействовать таким расширениям.
- Переберите остальные стратегии, особенно если раньше всё работало.
- См. также [#251](https://github.com/ShogunHeadStride/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS включён](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается сайт YouTube, и запустить именно её.
- В `service.bat` откройте `Run Diagnostics` и очистите там кэш Discord.
- Снова проверьте приложение Discord после очистки кэша.
- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если Discord не запускается и в браузере, повторно проверьте все стратегии. YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/ShogunHeadStride/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/ShogunHeadStride/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Обычно стоит сделать следующее:
- через `service.bat` обновить ipset и активировать `Game Filter`
- если это не помогло, дополнительно включить режим `ipset any`

Учитывайте, что `ipset any` может нарушить открытие множества сайтов. Не держите этот режим включённым постоянно: выясните IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`

Если проблема сохранится, создайте обсуждение в разделе [Discussions](https://github.com/ShogunHeadStride/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [здесь](https://github.com/ShogunHeadStride/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены-исключения, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** будут созданы автоматически при первом запуске `zapret` или `service.bat`
